# Chapter 1 — An Introduction to Large Language Models

> **Difficulty:** 🟢 Beginner — no prior AI knowledge needed
> **Estimated Time:** 3 days × 1 hour
> **Hands-on:** Yes — you will generate your first text with a real LLM

---

## 🎯 What You Will Learn

By the end of this chapter you will be able to:

- [ ] Explain what Language AI is and how it evolved over time
- [ ] Describe the difference between a **Representation Model** and a **Generative Model**
- [ ] Explain what **Attention** is and why it was a breakthrough
- [ ] Understand how LLMs are trained (pre-training vs fine-tuning)
- [ ] Know when to use a proprietary API vs an open model
- [ ] Run a real LLM and generate text with Python
